# Count Employees by Designation

## Problem Statement

Assume another column `designation`. Display `designation` and the number of employees.

## Goal

Group employees by designation and count employees in each role.

## Solution Approach

Use `GROUP BY designation` with `COUNT(*) AS employee_count`.

## Mistakes Made

No mistakes were made for this problem.

## Key Learning

Standard grouping pattern applies to any categorical column, providing count distributions.
